# super-agent

A from-scratch, general-purpose task agent (TypeScript / Node, pluggable model backends), built to learn agent architecture hands-on. See `docs/agent-research.md` and `docs/our-agent-design.md`.

## Agent skills

### Issue tracker

Issues & PRDs live as GitHub issues, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical roles, label strings unchanged. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
